# FinderHotKey

一个常驻后台的 macOS 小工具，提供三个全局快捷键：

| 功能 | 默认快捷键 |
| --- | --- |
| 打开访达（每次新建窗口，可自定义位置） | ⌘E |
| 最小化当前窗口（连续按可依次最小化） | ⌘esc |
| 显示桌面 / 恢复窗口 | ⌘D |

在“应用程序”中打开 FinderHotKey 会显示设置窗口，分成“快捷键”“触发提示”“菜单栏”三组：勾选或取消勾选来启用/停用功能，点击快捷键后直接按下新的组合键即可重新绑定。修改会先暂存，保存按钮在有修改后才可用；点击“保存”才生效并关闭窗口，直接关闭窗口会放弃修改。关闭设置窗口后应用继续在后台运行，没有 Dock 图标；菜单栏图标可在设置中关闭。任一快捷键触发时，屏幕中央会短暂显示该快捷键（仿微信提示的深灰圆角卡片、白色大字，不显示中文），可在设置中开关提示、调整停留/淡出时间以及背景和文字颜色。

## 工程结构

```
FinderHotKey/
├── Package.swift                     Swift Package 定义（可用 Xcode 打开）
├── Info.plist                        App 元数据（LSUIElement 等）
├── Sources/FinderHotKey/main.swift   全部源码
├── Resources/AppIcon.icns            应用图标
├── Scripts/build-app.sh              通用二进制构建脚本
├── dist/                             构建产物
└── README.md
```

## 构建

```bash
cd ~/FinderHotKey
./Scripts/build-app.sh
```

脚本会分别编译 Intel（x86_64）和 Apple Silicon（arm64），用 `lipo` 合并，组装 `dist/FinderHotKey.app` 并做 ad-hoc 签名。要求已安装 Xcode 命令行工具。

生成安装包：

```bash
./Scripts/build-pkg.sh
```

输出 `dist/FinderHotKey-<版本>.pkg`。安装包的 postinstall 会写入当前用户的 LaunchAgent，并在升级时清理旧的辅助功能授权（因为 ad-hoc 签名的授权绑定到二进制指纹）。

也可以直接用 Swift Package 构建本机架构：

```bash
swift build -c release
```

## 运行

```bash
open dist/FinderHotKey.app
```

首次运行需要在「系统设置 › 隐私与安全性 › 辅助功能」中勾选 FinderHotKey。没有辅助功能权限时，打开访达仍可用，但最小化窗口和显示桌面不会工作。

## 安装与开机启动

- 将 `FinderHotKey.app` 拖入 `/Applications`。
- 新建 `~/Library/LaunchAgents/local.tgs.finderhotkey.plist` 指向该路径，或使用安装包自动配置。
- 应用自身不写任何日志；LaunchAgent 的 stdout/stderr 指向 `/dev/null`。

## 快捷键定制

设置窗口中的每一行包含：

- **启用**：取消勾选后该功能会停用；点击“保存”后生效。
- **快捷键**：点击后变为“按下快捷键…”，此时所有全局快捷键会临时注销，按下新的组合键即可记下；按 Esc 取消。点击“保存”后生效。
- 组合键必须包含 ⌘、⌥ 或 ⌃ 中的至少一个；功能键（F1–F20）可以单独使用。与其他功能重复时会提示冲突。
- 「恢复默认」把快捷键、触发提示的开关、时间与颜色重置为默认值，同样需要点击“保存”才会生效。
- 「显示触发提示」勾选后，任意快捷键触发时屏幕中央会显示该快捷键：深灰（#4C4C4C）圆角卡片、白色系统字体，不显示功能名称。“停留”是保持完全显示的时间，结束后在“淡出”时间内逐渐消失；单位毫秒（0–5000，默认 600 / 200）。该提示不接收鼠标事件，也不抢夺焦点，只作触发反馈。
- 「提示颜色」提供“背景”和“文字”两个色块，点击后打开系统颜色选择器，可设置颜色和透明度；点击“保存”后生效。
- 「打开位置」可以自定义“打开访达”进入的文件夹，默认是主目录；点“选择…”后点击“保存”生效。若所选文件夹之后被移动或删除，会自动回到主目录。
- 每按一次“打开访达”都会新建一个访达窗口，窗口位置完全交给访达（与系统默认一致，通常出现在上一个访达窗口附近），应用不会移动窗口。这需要允许应用通过“自动化”控制“访达”：首次使用时系统会询问，只有在权限被拒绝时才会退化为打开或激活已有窗口。
- 「在菜单栏显示图标」控制菜单栏图标是否显示；点击“保存”后生效。关闭后应用仍完全在后台运行，再次打开 App 即可显示设置窗口。

所有修改先暂存在窗口中，点击“保存”后才写入设置并生效，保存按钮随后变灰、窗口关闭。直接点窗口红色关闭按钮会放弃未保存的修改。

设置保存在 `~/Library/Preferences/local.tgs.finderhotkey.plist`。

## 菜单栏与后台运行

- 应用没有 Dock 图标（`LSUIElement`）。菜单栏图标默认显示，可在设置窗口中关闭。
- 左键点击 ⌘ 图标：打开设置；右键点击：设置、打开访达、退出。
- 在“应用程序”中打开 FinderHotKey（应用已在运行时再次打开也一样）会显示设置窗口。
- 点“保存”会保存并关闭设置窗口；点窗口红色关闭按钮会关闭并放弃未保存的修改。快捷键继续生效。
- 点设置窗口左下角的“退出”（或菜单栏右键菜单中的“退出”）才会停止快捷键；下次登录或重新打开应用后恢复。

## 说明

- 显示桌面使用系统自带的“显示桌面”快捷键（默认 fn+F11），会读取系统当前绑定，因此不会破坏台前调度。
- 打开访达使用“自动化 › 访达”权限新建窗口；最小化窗口和显示桌面使用“辅助功能”权限。
- 本应用为 ad-hoc 签名，未经过公证。拷到其他 Mac 上若被 Gatekeeper 拦截，请在 Finder 中右键 App 选择“打开”，或在“系统设置 › 隐私与安全性”中点“仍要打开”。
- 重新构建后签名指纹会变化，辅助功能和自动化权限需要重新勾选。
